# Дом с верандой — варианты планировки

Каждый вариант — самостоятельная HTML-страница: 3D-модель, планы этажей, фундамент, схема участка. Открывается в браузере; three.js грузится с cdnjs, а без интернета — из `three.min.js` рядом.

| Файл | Что внутри |
|---|---|
| `v1-kuhnya-sleva.html` | Выступ 7,7 м, несущая стена вдоль дома под коньком. Слева кухня-столовая, справа гостиная с П-образным диваном, вход и тамбур справа спереди. Артефакт: https://claude.ai/artifact/DFDAPZgEhgnCTk1ZiGr2zu |
| `v2-vhod-sleva.html` | Вход, тамбур и гардероб слева спереди, лестница у левой стены. Справа вдоль всего дома спереди кухня-столовая, сзади гостиная, между ними стеклянные раздвижные двери. Артефакт: https://claude.ai/artifact/3iNbKe61ds9eAX2H2THzCe |
| `v3-kuhnya-gostinaya-u-vhoda.html` | Вход, тамбур, кухня-столовая и гостиная слева; справа холл с лестницей (ступени 250 мм), санузел, бойлерная, кладовка, спальня сзади и гостевая спереди. Артефакт: https://claude.ai/artifact/2fQcV7woFJbdg7w1L99MuV |
| `v4-shirina-10m.html` | Как вариант 3, но с 6,4 м от задней стены дом одной ступенькой расширяется к складу до 10 м (до склада везде 0,7 м). Кухня-столовая 31 м², крыша буквой Т. Артефакт: https://claude.ai/artifact/JNdo8EkxG9LTb8UJyd4uq7 |
| `v5-dvuskatnaya.html` | Форма как в варианте 4. Вход справа: крыльцо в правом переднем углу под вторым этажом, за ним тамбур-прихожая 6,5 м² со шкафом, вешалкой и обувницей. Слева гостиная у фасада, кухня с островом и в узкой задней части столовая; справа бойлерная 4,8 м², холл с лестницей, санузел, постирочная и спальня. Двускатная крыша с коньком над несущей стеной, второй этаж полумансардный, окна в левом скате. Артефакт: https://claude.ai/artifact/1E7rer6eFDHS2GWG5vcdFW |

## Сайт

`index.html` в корне репозитория — стартовая страница со ссылками на все варианты и превью планов (`dom/img/`). Её можно опубликовать через GitHub Pages: Settings → Pages → Deploy from a branch → ветка `claude/awesome-brahmagupta-5fpvqr`, папка `/ (root)`. Адрес будет `https://topgruzchik-sudo.github.io/Claude/`. Страницы закрыты от поисковиков (`noindex`), но открываются у любого, у кого есть ссылка.
